## Verification and remaining limits

The final full gate after the Tomcat patch and dependency restoration completed on 2026-10-06 with exit code 1. Only frontend audit and backend Dependency Check fail; all other checks completed and passed. Backend: 371 tests, none failed/errored/skipped. SpotBugs + Find Security Bugs: zero findings after only the approved exceptions. Frontend: 80 tests passed, and production build succeeds with Tailwind 3.3.3 and all original dependency majors. Lint has zero errors and ten existing hook warnings. Gitleaks scans 222 commits and current files with zero leaks; a separate random-canary probe confirms generic-api-key remains active. Semgrep passed with strict parsing. All four required headers were present on both live servers, including the patched Backend. NVD initialization/scanning is complete: first scan 20:27 minutes, final cached scan 14.204 seconds. The actual full-gate log/exit status are in backend/target/security-gate/full-gate-original-majors.log and full-gate-original-majors.exit.

Live backend validation uses an isolated in-memory H2 database, demo seeding disabled and a temporary random JWT key. Temporary validation servers are stopped after verification. The user's PostgreSQL container remains running and its data were not changed. This does not validate PostgreSQL connectivity or existing production data.

Frontend dependency acceptance fails (seven high and one critical finding); retaining all original dependency majors prevents claiming full acceptance. Backend dependency acceptance fails on CVE-2022-31691 in DevTools, a probable name-matching false positive when compared with the vendor's Spring Tools IDE advisory; no additional exception is applied. Mutable representation warnings are an accepted exception. The limiter is per JVM and currently groups backend requests from the same Next.js proxy address; production needs trusted client-address handling and a shared limiter. Production CSP still allows inline scripts/styles. Gateway callbacks require ADMIN pending a gateway-specific signature verifier. The registry flags ESLint 9.39.5 as no longer supported. Static heuristics and scanner results do not prove absence of every vulnerability.
